「簡易DBテーブル構造」の特徴

コードの冒頭にある SURVEY_DB という設定テーブル（表）を書き換えるだけで，HTMLに一切触れることなく以下のすべての操作が可能．

1．5種類の回答形式（type）に標準対応:
● "radio"：単一回答（ラジオボタン）
● "checkbox"：複数回答（チェックボックス／複数選ばれた場合はカンマ区切りで記録）
● "likert"：5段階尺度ボタン（横並びの1〜5ボタン）
● "text"：自由記述（1行テキスト入力）
● "textarea"：自由記述（複数行の長文入力）

2．必須・任意の自動切り替え（required）:
● true にすると赤い 「必須」 バッジが付き，未回答での送信をブロックする（複数回答の「最低1つ選択」の判定も自動で行う）．
● false にするとグレーの 「任意」 バッジが付き，空欄のままでも次へ進める．

3．選択肢の簡易記述（options）:
["10代", "20代", "30代"] のように文字を並べるだけでも，Rでの分析用に [{label: "男性", value: "M"}, ...] と記録用の値を分けて書くことも可能．
